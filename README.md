# Student Management System

A console-based student management project built with Java, JDBC, and MySQL.

## Features

- Add a student
- Update a student's name, course, or age
- Delete students by name, ID, course, course ID, or age
- View the student list

## Requirements

- Java 21
- Maven
- MySQL

The project connects to the `sql_practise` database. Set the `MYSQL_PASSWORD` environment variable in your IntelliJ run configuration before running `Main`.

## Run

Open the project in IntelliJ IDEA and run `Main`.
